組合語言語法速查 
; 分號後面是註解
.equ SPEED, 5        ; 常數
.reg x v0            ; 暫存器別名
start:               ; 標籤
    ld x, 10         ; v0 = 10
    ld i, ball       ; I = ball 的位址
    drw x, x, 4      ; 畫 4 列 sprite
    jp start
ball:
    .px ".##."       ; 用像素畫 sprite
    .px "####"
    .db 0x3C, 0b0101, "hi"   ; 原始資料
    .dw 0x1234       ; 16 位元資料
    .ds 8            ; 保留 8 個位元組
    .org 0x300       ; 往後填空到指定位址
指令意思
cls ret exit清畫面、返回、結束程式
jp 位址 jp v0, 位址 call 位址跳躍、加偏移跳躍、呼叫子程式
se sne skp sknp條件跳過下一行:相等、不等、按鍵按下、按鍵沒按
ld vx, 值|vy ld i, 位址載入
ld vx, dt ld dt|st, vx ld vx, k讀寫計時器、等待按鍵
ld f|hf|b, vx ld [i], vx ld vx, [i]字型位址、BCD、批次存取記憶體
add or and xor sub subn shr shl算術與位元運算
rnd vx, 遮罩 drw vx, vy, 高度亂數、畫 sprite
high low scd n scr sclSUPER-CHIP:高/低解析度、捲動

數字可寫 10、0x0A、0b1010,也可以用 + - * / & | << >> 與括號組成運算式。負數會轉成補數,所以 add v0, -1 就是減 1。
